The Business Challenge

Why Traditional Resume Screening Breaks Down

Problem Statement
⚠️
Resume Keyword Padding

Candidates copy-paste modern keywords (Playwright, Agentic AI, MCP, RAG) into bare skills sections without having touched them in actual project deliverables.

  • Standard ATS searches match raw strings blindly.
  • No distinction between "hands-on expertise" and "passing buzzword".
⏳
Reviewer Fatigue & Inconsistency

Engineering managers and leads spend 30–45 minutes per profile reading lengthy 4–6 page PDFs, leading to subjective and inconsistent evaluation.

  • Inconsistent rubric application across interviewers.
  • Key qualification gaps missed before scheduling 1st technical round.
📉
Expensive Interview Waste

Unqualified candidates pass initial HR screens, consuming high-value senior engineering hours only to fail on core coding or hard requirements.

  • High cost per hire & bloated interview pipelines.
  • Zero structured audit trail of why candidates were screened in/out.

Agent Execution Pipeline
STEP 1 Taxonomy Mapping: Parse JD into weighted mandatory & good-to-have matrices.
STEP 2 Document Ingestion: Extract full text without hallucination or truncation.
STEP 3 Experience Gate: Check Exp < 6 yrs prior to scoring (Instant Fail if under).
STEP 4 Evidence Audit: Apply 4-tier status factor (Matched/Partial/Claimed/Missing).
STEP 5 Delivery: Render Markdown + HTML + Headless Edge PDF simultaneously.
Core Innovation

The "No-Skill-Inflation" Evidence Engine

Evidence Verification

Unlike standard search tools, the agent demands verifiable project deliverables. A bare keyword in a skills tag cloud is NEVER awarded full points.

Matched (M) • 1.0× Concrete Evidence

Skill is demonstrated in ≥1 project with tangible output. E.g.: "Migrated test suite to Playwright JS, cutting runtime by 45%."

Partial Match (P) • 0.6× Adjacent / Tangential

Adjacent tech used or passing project mention without full framework ownership. E.g., Web UI testing without explicit Cucumber BDD.

Claimed (C) • 0.3× Resume Tag Padded

Appears in technical skills summary or tools bullet list, but zero deliverables exist in project history. Flags interview probe.

Missing (U) • 0.0× Zero Mention

Does not appear anywhere under the name, abbreviation, or verified industry synonyms.

🛡️ Anti-Hallucination Guardrail: The agent is strictly constrained to the text extracted from the file. It cannot "infer" that a candidate knows Python just because they know Java, unless explicitly written and evidenced.
Evaluation Rubric

100-Point Scoring Model & Hard-Fail Overrides

Rubric Logic
📊
Score Capacity Formula
ComponentMax WeightDescription
Mandatory Skills 85 Pts 13 Core SDET skills (Languages, Playwright, Frameworks, UI/BDD, APIs, STLC, AI Testing)
Good-to-Have Bonus 10 Pts Cloud (AWS/Azure), CI/CD, Pharma/Life Sciences domain, Low-code, Monitoring
Experience Fit 5 Pts 6–10 Yrs (5 pts), 11–12 Yrs (3 pts), >12 Yrs (2 pts), <6 Yrs (0 pts / Gate Fail)
TOTAL CAPACITY 100 Pts ≥80: Strong Fit | 60–79: Potential Fit | 40–59: Weak | <40: Reject
🛑
Hard-Fail & Override Rules
Rule 1 — Experience Gate: Total Experience < 6.0 years → Automatic Instant Rejection prior to scoring.
Rule 2 — Core Language: Neither JS/TS nor Python evidenced → Reject regardless of score.
Rule 3 — AI Hard Gap: Both AI Testing & Agentic AI missing → Cap score at < 60 and downgrade verdict tier.
Rule 4 — Skills Padding: ≥ 3 claimed unevidenced skills triggers interview red flag and tier penalty.
