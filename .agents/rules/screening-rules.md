# Candidate Screening Rules & Rubric Enforcement

## 1. No Skill Inflation
- Skills listed in bullet points or summaries without project deliverables are classified as Claimed (0.3x).
- Never credit an unevidenced skill as Matched.

## 2. Mandatory Overrides
- **Experience Gate:** If total experience < 6.0 years, immediately fail and disqualify candidate.
- **Rule #3 AI Gap:** If AI Solution Testing and Agentic AI are missing, cap score at < 60 and downgrade verdict tier.
- **Reports Organization:** All output files (.md, .html, .pdf) must be placed in Reports/<YYYY-MM-DD_HH-MM-SS>/.
